# Japanese Phrase Search

CSV / Excel 内の日本語文章（「本文」列）を完全一致で検索し、一致箇所のみ黒・太字、それ以外の文脈をグレーで表示する Streamlit アプリです。

## セットアップ

```bash
python -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

依存関係をインストールします。

```bash
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

「データセット」プルダウンからファイルを選び、検索フレーズを入力してください。
アプリと同じディレクトリ、または `data/` ディレクトリに置いた `*.csv` / `*.xlsx` / `*.xls` がプルダウンに表示されます。それ以外のファイルは「ファイルをアップロード…」から読み込めます。

サンプル（`data/sample_issuer_reports.*` と、格付会社レポートの文体を模した `data/sample_rating_reports.*`。いずれも架空データ）は `python make_sample_data.py` で再生成できます。

検索結果の文章をクリックすると、全文が（一致箇所をハイライトしたまま）展開されます。

## ユーザーと検索履歴

- サイドバーの「ユーザーを選択」で検索するユーザーを選びます（「＋ 新しいユーザーを追加…」で追加。認証はなく、履歴を分けるための名前です）。
- 選択中のユーザーの検索が自動で記録されます（1ユーザー最大200件。入力途中の語は1件にまとめ、同じ語は先頭に寄せます）。
- 検索語が空のトップ画面の下に「最近の検索」を表示します（直近10件、それ以前は折りたたみ）。語をクリックすると検索フレーズに入力されます。「履歴を消去」でそのユーザーの履歴を削除します。
- 履歴はアプリ直下の `.search_history.json` に保存されます（git 管理外）。

## 入力ファイルのフォーマット

CSV または Excel（先頭シート）で、1 行目を次の列名にしてください。**検索対象は「本文」列のみ**です。

```
発行体ID, 発行体コード, 年, 公表日, 発行体名(CDEX), 発行体名(業務), 業種, 担当部署,
担当アナリスト, 公表日, 発行体格付, 格付の方向性, 格付アクション, タグ, 本文
```

- 「本文」列が無いファイルはエラーになります。他の列が欠けている場合は警告のみで、該当する表示・絞り込みが省略されます。
- 「公表日」が 2 回出てきますが、そのまま読み込めます（表示には 1 つ目を使用）。
- 全列を文字列として読むため、ID・コードの先頭ゼロは保たれます。
- 結果には発行体名・年・公表日・業種・格付・アクション・担当・タグを表示し、サイドバーで 年 / 業種 / 担当部署 / 格付アクション に絞り込めます。

## 現在の検索仕様

- 入力文字列の literal な完全一致
- 1 行に複数一致がある場合はすべてハイライト
- 一致部分は黒・太字
- 前後文脈はグレー
- CSV は UTF-8 / UTF-8 BOM / CP932 / Shift-JIS を順に試行（Excel は openpyxl / xlrd で読み込み）
- 表示件数と前後文脈長を GUI から変更可能

この初期版は全行を逐次検索します。数十万〜数百万行規模で入力ごとの応答速度が問題になる場合は、trigram index や SQLite FTS / Elasticsearch / OpenSearch に検索層を置き換える構成が適しています。
