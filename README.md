# Japanese Phrase Search

CSV / Excel 内の日本語文章（「本文」列）を完全一致で検索し、文章は黒、一致箇所を赤・太字で表示する Streamlit アプリです。検索結果は「年の新しい順 → 格付の高い順（AAA→D）→ 業種」で並びます（同じ並びで公表日の新しい順、発行体名と続き、同じレポートの文は元の順を保ちます）。

## セットアップ

```bash
python -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

依存関係をインストールします。

```bash
pip install -r requirements.txt
```

## 起動

```bash
streamlit run app.py
```

「データセット」からファイルを選び、検索フレーズを入力してください。
アプリと同じディレクトリ、または `data/` ディレクトリに置いた `*.csv` / `*.xlsx` / `*.xls` が選択肢に表示されます。それ以外のファイルは「ファイルをアップロードして追加」から読み込めます。

## 複数ファイルの読み込み（データの追加）

複数のファイルを読み込むと、行をつないで1つのデータとして検索・集計します。

- **Streamlit 版**: 「データセット」で複数のファイルを選ぶか、「ファイルをアップロードして追加」で複数のファイルをアップロードします。
- **新しい画面**: 上部のデータ名をクリックし、まとめたいファイルにチェックを入れます（チェックした順につなぎます）。「＋ ファイルを追加…」でアップロードしたファイルは今のデータに加わり、「ファイルを開く…」は今のデータを置き換えます。選んだ組み合わせは次回も維持され、検索履歴にも記録されます。
- **HTML 単体版（search.html）**: 「＋ ファイルを追加」またはファイルのドロップで今のデータに加わり、「ファイルを開く」は置き換えます。同じ名前のファイルを追加すると、新しい内容に差し替えます。読み込んだファイルは一覧の「×」で外せ、すべてブラウザに保存されて次回も復元されます。
- **重複する行**: 前に読み込んだファイルと同じ行（発行体ID(業務)・公表日・本文が同じ行。これらの列が無いデータでは全列が同じ行）は、後のファイルから除きます。同じファイルの中の重複は残します。除いた行数はファイルごとに表示されます。
- 列は名前で揃えます。あるファイルに無い列は、そのファイルの行では空欄になります。
- 2つ以上のファイルをまとめると「ファイル」列（行の元のファイル名）ができ、絞り込みと結果の表示に使えます。

サンプル（`data/sample_issuer_reports.*`: 18行の簡易版、`data/sample_rating_reports.*`: 70発行体×2015〜2025年の約860行、`data/sample_rating_sentences.*`: それを1文1行に分割した7,500行超で、実データと同じ形式の動作確認用）はいずれも架空データで、`python make_sample_data.py` で再生成できます。後者は格付投資情報センター（R&I）のレポートを想定し、R&I の格付記号（AAA〜BBB-）と方向性（ポジティブ/安定的/ネガティブ）、「格付理由 → 格付の方向性 → 今回の判断」の構成に沿っていますが、本文は実在レポートの転載ではなく、定型文の組み合わせで生成しています。

検索結果の文章をクリックすると、全文が（一致箇所をハイライトしたまま）展開されます。

## フォントと文字サイズ

サイドバーの「表示」で変更できます（選択は `.search_history.json` に保存され、次回起動時も維持されます）。

- **フォント**: 既定は BIZ UDPゴシック。BIZ UDゴシック / BIZ UDP明朝 / Noto Sans JP / Noto Serif JP / Zen Kaku Gothic New / IBM Plex Sans JP（Google Fonts から読み込み）、ヒラギノ角ゴ / 游ゴシック / メイリオ（端末にあるフォント）から選べます。「その他」を選ぶとフォント名を直接入力できます（Google Fonts にある名前か、端末にインストール済みの名前）。
- **文字サイズ**: 12〜32px（既定 18px。Streamlit 標準は 16px）。画面全体が連動して拡大・縮小します。
- Google Fonts はインターネット接続が必要です。オフラインや読み込み失敗時は、ヒラギノ角ゴ / 游ゴシック / メイリオなど端末のフォントで代替表示されます。
- 表（`st.dataframe`）は Streamlit の仕様でフォントを変えられず、その部分は標準フォントのままです。グラフの文字はフォント・サイズに追従します。

## 2つの語での検索

「検索フレーズ」の横の「検索フレーズ2（任意）」に2つ目の語を入れると、「2語の条件」で組み合わせて検索します（1つ目だけ、または2つ目だけの入力なら、その1語で検索します）。

- **両方を含む（同じ文）**: 1行（1文）の中に両方の語が入っている行。
- **両方を含む（同じレポート内）**: 別の文でも、同じレポート（発行体ID＋公表日）のどこかに両方の語が入っていれば一致とし、そのレポート内で語を含む行を結果に出します（レポートを識別できるデータで選べます。既定）。
- **どちらかを含む**: どちらか一方でも含む行。
- 結果では両方の語をハイライトします。件数の集計・共起語も、この条件で一致したものを対象にします（共起語の候補からは、2つの検索語そのものを除きます）。
- 検索履歴・「最近の検索」には2語と条件も保存され、クリックで復元できます。

## 除外フレーズ

検索欄の下の「除外フレーズ（任意・スペース区切り）」に入れた語に含まれる部分は、一致として数えません。

- 例: 「強固」で検索し「比較的強固」を除外すると、「比較的強固」の中の「強固」は一致しません。同じ文に単独の「強固」もあれば、そちらは一致します。
- 検索結果のハイライト、件数の集計、共起語のすべてに反映されます（共起語では、除外フレーズの部分を語の切り出しからも外します）。
- Streamlit 版では除外フレーズは検索履歴に保存されません（新しい画面では保存されます）。

## ユーザーと検索履歴

- サイドバーの「ユーザーを選択」で検索するユーザーを選びます（「＋ 新しいユーザーを追加…」で追加。認証はなく、履歴を分けるための名前です）。
- 選択中のユーザーの検索が自動で記録されます（1ユーザー最大200件。入力途中の語は1件にまとめ、同じ語は先頭に寄せます）。
- 検索語が空のトップ画面の下に「最近の検索」を表示します（直近10件、それ以前は折りたたみ）。語をクリックすると検索フレーズに入力されます。「履歴を消去」でそのユーザーの履歴を削除します。
- 履歴はアプリ直下の `.search_history.json` に保存されます（git 管理外）。

## 入力ファイルのフォーマット

CSV または Excel（先頭シート）で、1 行目を次の列名にしてください。**検索対象は「本文」列のみ**です。

```
発行体ID(業務), 発行体コード(業務), 証券コード(CDEX), 年(CDEX), 公表日(CDEX),
発行体名(CDEX), 発行体名(業務), 業種(業務), 担当部署(業務), 担当アナリスト(CDEX),
公表日(業務), 発行体格付(業務), 格付の方向性(業務), 格付アクション(業務), タグ, 本文
```

- 「本文」列が無いファイルはエラーになります。他の列が欠けている場合は警告のみで、該当する表示・絞り込みが省略されます。上記以外の列は読み込まれません。
- 全列を文字列として読むため、ID・コードの先頭ゼロは保たれます（「年(CDEX)」のみ整数に変換）。
- 結果には発行体名・年・公表日・業種・格付・アクション・担当・タグを表示します。
- サイドバーの絞り込み: 「年(CDEX)」は範囲スライダー（初期範囲は 2016〜2026 年。データがこの範囲の外にあるときは全期間）、「発行体格付(業務)」「業種(業務)」「担当部署(業務)」「担当アナリスト(CDEX)」「格付アクション(業務)」は複数選択（未選択＝すべて。格付は AAA→D の順に並びます）。

## 巨大ファイルの扱い

- 初回読み込み時に、必要な列だけを Parquet に変換して `.cache/` に保存します（git 管理外）。2回目以降（アプリ再起動後も）は Parquet から読むため、Excel を含め大幅に速くなります。元ファイルを更新すると自動で作り直します。
- CSV は pyarrow エンジンで読みます（失敗時は通常のエンジンに自動で切替）。
- 絞り込み列はカテゴリ型で保持し、検索は全行を一括判定してから上位の結果だけを整形します。

## 検索結果の分析

一致が1件以上あると、検索結果の上に表示切替（検索結果 / 件数の集計 / 共起語 / 区分別の共起語）が出ます。選んだ表示だけを計算します。

- **件数の集計**: 「集計の軸」を1つ以上選べます（例: 発行体格付 × 業種。選んだ順に左→右の軸）。選べる軸は 発行体格付 / 格付の方向性 / 格付アクション / 業種 / 年 です。
  - 各組み合わせの一致件数・全文書数に加え、**一致率**（Wilson の 95% 信頼区間つき）、**全体比**（一致率 ÷ 全体の一致率）、**期待件数**、**標準化残差**（絶対値が 2 を超えると偶然とは考えにくい偏りの目安）を表示します。元の文書数が多い区分で件数が多くなる影響を、率と期待値との比較で補正するための指標です。
  - グラフの指標は 一致件数（既定） / 一致率 / 全文書数 / 全体比 / 標準化残差 から選べます。1軸は棒グラフ（一致率のときは黒線＝信頼区間、点線＝全体の一致率）、2軸はヒートマップ、3軸以上は表のみです。
  - 横軸のラベルは間引かず全部表示します。カテゴリが多いときは図の幅を自動で広げるため、画面幅を超える場合は横にスクロールします。
  - 並び順（軸の順 / 一致率 / 全体比 / 標準化残差 / 一致件数）と、最小の全文書数（件数が少ない組み合わせを除く）を指定できます。
- **集計の単位**（件数の集計・共起語の共通）: 「文（1行を1件）」と「レポート（発行体ID＋公表日で1件）」を切り替えられます。既定はレポートです。
  - レポート単位では、発行体ID(業務)と公表日(業務)（無ければ公表日(CDEX)）が同じ行を1件にまとめ、1行でも一致すれば一致として数えます。軸（格付・業種など）の値はレポートの先頭行から取ります。共起語は、レポート内の全行の語をまとめて数えます。
  - 実データのように1文1行のデータでは、文数の多いレポートが件数・一致率で有利になるため、レポート単位で見るのが基本です。1行1レポートのデータでは、どちらを選んでも同じ結果になります。
- **共起語**: 一致した文書に特に多く出る語を、全文書の無作為標本と比較して表示します。「特徴度」は 2×2 の対数尤度比（G²）、「リフト」は一致文書での出現率 ÷ 比較対象での出現率です。並び順は 出現文書数（既定） / 特徴度 を選べます。
- **区分別の共起語**: 「集計の軸」（複数可。既定は発行体格付）の組み合わせごとに、一致文書の中でその区分に特に多い語を表示します。
- 語は単位（文／レポート）ごとに数えます（同じ語が1単位に複数回出ても1回）。検索語そのものと格付記号（AA, BBB- など）は除きます。「分析の設定」で、語の切り出し方法・並び順・表示語数・最小出現数・除外語を調整できます。表示語数は既定で全語（「語を全て表示」をオフにすると 10〜500 語で指定）です。
- 語の切り出しは、既定が「高速（漢字・カタカナ・英字の連なりで分割）」、Janome がインストールされていれば「形態素解析（名詞）」も選べます（精度は高いですが遅く、結果は文書ごとに記憶されます）。
- 既定では全件を解析します（「全件を分析に使う」がオン）。巨大データで重いときはこれをオフにすると、解析する単位（文／レポート）を一致側・比較側とも「分析に使う最大件数」（100〜3000、既定 500）まで無作為に抽出します。件数の集計は、この設定にかかわらず全文書が対象です。

## 現在の検索仕様

- 入力文字列の literal な完全一致
- 1 行に複数一致がある場合はすべてハイライト
- 一致部分は黒・太字
- 前後文脈はグレー
- CSV は UTF-8 / UTF-8 BOM / CP932 / Shift-JIS を順に試行（Excel は openpyxl / xlrd で読み込み）
- 除外フレーズに含まれる部分は一致としない（上の「除外フレーズ」を参照）
- 前後の表示文字数（10〜120、既定 45）をサイドバーで変更可能
- 検索結果は既定で全件表示。「全件表示」をオフにすると最大表示件数（10〜2000）を指定可能

検索は索引を使わず、入力のたびに全行を一括で判定します。数十万〜数百万行規模で入力ごとの応答速度が問題になる場合は、trigram index や SQLite FTS / Elasticsearch / OpenSearch に検索層を置き換える構成が適しています。

## HTML 単体版（search.html）

トップページの検索だけを、Python なしで使える 1 ファイルの HTML にしたものです。`search.html` と Excel（.xlsx）または CSV があれば、誰の環境でも使えます。画面の作りは、下の「新しい画面（試作版）」（`web/`）と同じです。

- 使い方: `search.html` をブラウザで開き、Excel / CSV を画面にドロップ（またはクリックして選択）します。ファイルはブラウザの中だけで読み込まれ、外部には送信されません。
- 読み込んだデータはブラウザ（IndexedDB）に保存され、次回からは選び直さなくても開けます。データを差し替えるときは「データを更新」から新しいファイルを選びます。
- 列は本アプリと同じ形式（「本文」列が必須）。Excel は先頭シートを読みます。古い `.xls` は非対応のため、`.xlsx` で保存し直してください。
- 検索フレーズ 1・2、2語の条件（同じ文 / 同じレポート内 / どちらか）、除外フレーズ、年・格付・業種・担当部署・担当・アクションでの絞り込み、最近の検索（ブラウザの localStorage に保存）、文字サイズ・前後の文字数・フォント・ライト/ダークの設定に対応しています。件数の集計・共起語・ユーザー別履歴は含みません。
- 結果は見えている行だけを描画するので、数万件ヒットしてもスクロールが重くなりません。
- キーボード: `/` または `⌘K` で検索欄へ、`↓` で結果へ、`↑↓`（`j` `k`）で移動、`Enter` で全文、`Esc` で検索欄へ戻る／入力をクリア。
- フォントは、オフラインで動くよう端末にインストール済みのものだけを使います（Google Fonts は読み込みません）。
- 動作環境: Chrome / Edge / Safari / Firefox の最近の版（Excel の展開に `DecompressionStream` を使います）。

## 新しい画面（TypeScript + FastAPI）

Streamlit 版を TypeScript（React + Vite）で作り直した画面です。入力のたびに画面全体が再実行されることがなく、文字を打つとその場で結果が変わります。Streamlit 版（`app.py`）も残しており、同じ `.cache/`（Parquet）と `.search_history.json`（検索履歴）を共有します。

- 構成: `server/`（FastAPI。データの読み込み、共起語の解析、検索履歴、アップロード）と `web/`（画面）。検索・絞り込み・件数の集計はブラウザの中で計算し、共起語（Janome を含む）はサーバーで計算します。
- 表示は上部のタブで切り替えます（キー `1`〜`4`）。検索語と絞り込みは切り替えても残ります。
  - **検索結果**: 一致箇所をハイライト。クリック／`Enter` で全文。見えている行だけを描画するので件数が多くても軽い。
  - **件数の集計**: 軸（格付・方向性・アクション・業種・年。選んだ順）ごとの一致件数・一致率・Wilson 95% 区間・全体比・期待件数・標準化残差。1 軸は棒グラフ、2 軸はヒートマップ（全セルに数値）、3 軸以上は表のみ。CSV で保存可能。単位は文／レポート。
  - **共起語**: 一致した文（レポート）に多い語を、全体との比較（出現率・リフト・特徴度 G²）で表示。語をクリックすると、検索語と同じ文に出てくる例を右に表示。語の切り出しは高速／形態素解析（Janome）。
  - **区分別の共起語**: 軸の値ごとに特徴的な語。語をクリックで使用例。
- ユーザー（右上）ごとに検索履歴を記録し、検索欄が空のときに「最近の検索」として表示します。除外フレーズも履歴に残ります。
- データセットの一覧の「＋ ファイルをアップロード…」で CSV / Excel を読み込めます（`.cache/uploads/` に保存され、次回も一覧に出ます）。
- 文字サイズ・前後の文字数・フォント・ライト/ダークは右上の ⚙ から。設定と分析の条件はブラウザに保存されます。
- キーボード: `/` または `⌘K` で検索欄へ、`↓` で結果へ、`↑↓`（`j` `k`）で移動、`Enter` で全文、`Esc` で検索欄へ戻る／入力をクリア、`1`〜`4` で表示の切り替え。
- 共起語の同点の並びは語の文字順に固定しています（`app.py` では実行ごとに同点の順が変わることがあります）。
